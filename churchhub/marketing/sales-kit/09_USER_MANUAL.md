# ChurchHub — User Manual

**Audience:** Pastors, treasurers, clerks, overseers (institution workspace)  
**Tip:** What you see depends on your **role** and **active church**.

---

## 1. Signing in

1. Open your ChurchHub URL  
2. Go to staff login (`/accounts/login/`)  
3. Enter username and password  
4. If MFA is required by policy, complete the challenge  
5. You land on **Mission Control** (dashboard)

**Members:** use the **Member Portal** login (`/portal/login/`) — not staff login.  
First-time portal password is often date of birth as `YYYY-MM-DD`, then you must set a new password.

---

## 2. Mission Control (everyone)

| Area | Use it for |
|------|------------|
| KPI cards | Monthly giving, remittance, membership pulse (scoped) |
| Action Queue | Your to-dos: visitors, transfers, approvals |
| Teller / finance | Business date and recent posting activity (treasury) |
| This Week Pulse | Birthdays, meetings, open follow-ups |
| Notifications | Bell / inbox for system notices |
| Church switcher | Select the church you are working in |

---

## 3. Clerk / secretary workflows

### Members
1. **Members → Directory**  
2. Search / filter → open profile  
3. Add member carefully (check duplicates)  
4. Maintain family, leadership, and life events as permitted  

### Visitors
1. Open **Visitors**  
2. Log guest + invite source + follow-up owner  
3. When ready: **Convert to member** (keeps history)  

### Transfers
Use the transfer register — don’t “edit church” as a shortcut.

### Announcements
Draft → submit → (approval if required) → publish. Check **Upcoming calendar**.

---

## 4. Pastor workflows

1. Start at **Action Queue** daily  
2. Clear open visitors and pending minutes  
3. **Meetings:** agenda → attendance → minutes → decisions  
4. Use calendar for the week’s pastoral rhythm  
5. Optional: review portal prayer/thanksgiving submissions if assigned  

---

## 5. Treasurer workflows

### Record a receipt
1. Finance → **Record Receipt**  
2. Confirm **business date**  
3. Member or anonymous + category/fund + amount + method  
4. Save → open **Confirmation** (print/file)  

### Expenses
**Record Expense** with the same discipline (approvals may apply).

### Approvals
**Pending Financial Approvals** — second pair of eyes when policy requires. Recorder should not approve their own item if SoD is enforced.

### Giving statements
**Giving Center** → select member → statement (permissioned).

### Remittance
Use **Cut-off** / remittance workspace and settlement desk per conference policy.

### Reports
**Reports** → Tithe & Offering, Financial Summary, Trial Balance (if entitled) → export for board packs.

**Never** ask IT to “fix a posted number” in place — request a reversal/void through the product.

---

## 6. Overseer / executive workflows

1. Mission Control KPIs across authorized churches  
2. Organization hierarchy for structure health  
3. Remittance cut-off totals  
4. Report Center roll-ups (district / conference as permitted)  
5. Spot-check permissions with admins quarterly

| Live meeting | Join when published |

---

## 8. Good habits

- Keep your active church correct before posting  
- Log out on shared computers  
- Don’t share passwords  
- Print or PDF confirmations for Sabbath audit files  
- Escalate permission issues to your administrator — don’t borrow accounts
