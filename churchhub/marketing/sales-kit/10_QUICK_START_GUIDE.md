# ChurchHub — Quick-Start Guide

**Goal:** First productive hour on a pilot site  
**You need:** Login, active church selected, chart of accounts seeded

---

## 15-minute orientation

| Min | Do this |
|-----|---------|
| 0–3 | Sign in → confirm your name/role on Mission Control |
| 3–5 | Set **active church** (not “All Churches” for posting drills) |
| 5–10 | Open **Action Queue** — note open items (don’t clear yet) |
| 10–15 | Click through Members · Finance · Church Life menus — see what *your* role shows |

---

## Clerk path (20 minutes)

1. **Members → Directory** — search a sample member; open profile  
2. **Visitors** — add a test visitor (mark clearly as TEST)  
3. **Announcements** — draft “Pilot kickoff” (don’t publish until approved)  
4. **Calendar / Upcoming** — confirm the week view loads  

---

## Treasurer path (25 minutes)

1. Note **business date** on dashboard / receipt form  
2. **Record Receipt** — small TEST tithe/offering  
3. Land on **Confirmation** — print or screenshot for the pilot folder  
4. Open **Transaction Register** — find your TEST row  
5. **Giving Center** — open statement for a demo member  
6. **Reports → Tithe & Offering** — run current month  

If approvals are on: submit and have a second user approve.

---

## Pastor path (15 minutes)

1. Clear or comment one **Action Queue** visitor item  
2. Open an upcoming **Meeting** — skim agenda/minutes  
3. Check **This Week Pulse** / calendar for birthdays  

---

## Admin path (20 minutes)

1. **Users** — confirm invited pilot users exist  
2. **Permissions → Matrix** — show least privilege to stakeholders  
3. **Organization** — verify hierarchy labels look right  
4. If platform pilot: glance `/platform/` tenancy (operators only)  

---

## End-of-day pilot checklist

- [ ] TEST transactions labeled or voided per finance lead  
- [ ] Real PII not used in screenshots for marketing  
- [ ] Working day closed if required by policy  
- [ ] Questions logged for hypercare  

---

## Common first-day blockers

| Blocker | Fix |
|---------|-----|
| Blank finance modules | Feature flags / permissions |
| “Permission denied” | Wrong role or church context |
| Portal mail links broken | Public URL env on server |
| No sample members | Run seed / import before workshop |
