# Videos

This folder is intentionally empty until a demo is **recorded** from a live ChurchHub session.

## Quick start (10-minute demo)

1. Seed demo data; keep Platform Control in a second browser profile (already logged in).
2. Open teleprompter: [`../demo-script/TELEPROMPTER_10MIN.txt`](../demo-script/TELEPROMPTER_10MIN.txt).
3. Follow timing: [`../demo-script/DEMO_SCRIPT_10MIN.md`](../demo-script/DEMO_SCRIPT_10MIN.md).
4. Record the browser window (not the whole desktop if possible).

## Suggested filenames

| File | Length | Purpose |
|------|--------|---------|
| `ChurchHub_Demo_10min.mp4` | ~10:00 | Full executive demo |
| `ChurchHub_Teaser_60s.mp4` | ~0:60 | Homepage / social |
| `ChurchHub_Treasury_3min.mp4` | ~3:00 | Treasurer-focused cut |
| `ChurchHub_Portal_Mobile.mp4` | ~1:00 | Member portal phone view |

## Recording tools (Windows)

| Tool | Notes |
|------|--------|
| **OBS Studio** | Best quality; record browser source or window |
| **Win + G** (Game Bar) | Quick local capture |
| **Zoom / Teams** | Local recording if presenting live |

**Tips:** 1080p · 30 fps · hide desktop icons · mute notifications · use teleprompter on a second screen · one clean take beats heavy editing.

## After recording

1. Save exports in this folder.
2. Keep masters offline; commit only compressed, PII-safe cuts if the repo should hold them (large MP4s often stay in cloud storage / Drive instead of git).
